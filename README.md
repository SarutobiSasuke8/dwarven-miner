# Dwarven Miner

Idle Miner Tycoon-style game with a dwarven theme. Built in Godot 4.

Classic loop: **Mine Shafts** → **Elevator** → **Warehouse** (with bottlenecks).

## Features in this starter
- Multiple shafts with production rates
- Elevator and Warehouse throughput
- Manual tapping + Manager automation
- Idle / offline cash calculation
- Upgrade system with scaling costs
- Local save/load
- Dwarven resource names and structure ready for art + Suno audio

## How to run
1. Open the project in **Godot 4.x**
2. Press F5 (or the Play button)
3. Tap the mine area or use the buttons to progress

## Export for browser (HTML5)
- Project → Export → Add Web preset
- Export and host the files (or upload to portals)
